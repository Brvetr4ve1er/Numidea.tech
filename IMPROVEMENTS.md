# Improvements: backlog, decisions and metrics

The site's running to-do list, kept by the weekly improvement cycle (a scheduled session every Monday). Each cycle:
1. measures the live site (`npm run metrics`, the live audit, Lighthouse, links) and appends one row to the metrics history;
2. ships up to five items whose authority allows it, each with every gate green;
3. reports to the owner.

Not deployed (`scripts/site.mjs` NOT_DEPLOYED).

**Authority (the owner's rule, 2026-10-26):**
- **clear-cut:** technical faults, dead things, duplicates that add nothing, and plainly wrong wording that needs no new fact. Done without asking.
- **owner-decision:** cutting, merging or rewriting a section, or changing an offer, a price or the substance of a claim. Waits for the owner's yes, recorded under Decisions.
- **owner-facts:** needs information only the owner has. Waits for it; nothing is ever invented.

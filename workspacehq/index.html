FAQ

Questions, answered.

What does WorkspaceHQ actually scan?

Git status, branches, unpushed and uncommitted work, build and test state, and secrets sitting in plain text, across every folder you point it at.

Do I have to play the game part?

The game is a lens over real work. Every quest maps to a real fix in a real repo, and XP only moves when your workspace actually gets healthier.

Where does my code go?

Scans run on your machine. When you ask Claude something, only the question and the repo context it needs are sent.

What is Bit, really?

A status light with a personality. His mood mirrors your workspace at a glance, so you can tell how things are without reading a single number.

How do I start?

Clone the repo from GitHub and follow its README. Run a scan and your first quest shows up on top. That's it.

## Owner feedback that drove it (2026-11-25 late)
- "The text and the typography overall is not following any structure. Research how typography is actually done."
- On the 3D books: "the arrangement of things is so 1-dimensional", "bad typography and bad sizing of items", "the courses are in such a boring font and the images are so boring, feels like a cheap knock-off of a real anime website", "a pretty good mediocre job".
- The thread agreed: the fix is a strict type system plus a graphic layer (tapes, big index numbers, cut-out characters breaking frames), not more art.

## Type system (draft)
- DISPLAY Archivo Condensed 900 caps · UI Archivo Expanded 800 caps · LABEL Geist Mono caps tracked · BODY Geist.
- Arabic: Reem Kufi (display/UI), Plex Arabic (labels/body), no caps, no tracking.
- Tokens in `hub/style.css`: `--f-cond`, `--f-wide`, `--fs-micro`…`--fs-index`, `--lh-*`, `--tr-*`. `hub/fonts/hud.css` is generated by `scripts/build-hub.mjs`; Lanterne pages link it via `scripts/lib/lanterne.mjs`.
- Baseline audit: 193 distinct font sizes across 3 sheets, 2 competing token sets, 3 display faces (Geist, Cinzel, Archivo).
- Open question in the spec: retire the Cinzel "Gravure" plates or not.
- Spec: https://claude.ai/artifact/BrvX62HC49TTPheF3Yiwhw
